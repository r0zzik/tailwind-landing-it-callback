# it-CALLBACK — лендинг

Учебный проект — адаптивный лендинг на Tailwind CSS.

## Что реализовано

- Хедер с бургер-меню (мобилка) и навигацией (десктоп)
- Секция «Hero» с заголовком, текстом и кнопкой скачивания PDF
- Секция «Курсы» — 3 карточки с иконками
- Секция «Наше будущее» — текст + картинка
- Секция «Как это работает» — 3 шага
- Секция «Тарифы» — 3 плана подписки
- Модальное окно «Политика конфиденциальности» с блокировкой скролла и закрытием по клику на фон
- Кнопка «Наверх» с плавным скроллом
- Адаптив: 375px, 768px, 1024px+
- Ховеры: `hover:scale-105`, `hover:shadow-xl`

## Стек

- HTML
- Tailwind CSS (v4)
- JavaScript

## Как запустить

1. Установить зависимости: `npm install`
2. Собрать Tailwind: `npx @tailwindcss/cli -i ./src/input.css -o ./public/output.css`
3. Открыть `index.html` в браузере
